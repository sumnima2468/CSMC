# Customer Segmentation Using Machine Learning and Clustering

This repository contains the work completed for my MSc Data Science dissertation.

The main purpose of the project is to group customers based on their behaviour and characteristics using unsupervised machine learning techniques.

The clustering methods used in this project are:

- K-Means
- DBSCAN
- Gaussian Mixture Model (GMM)

The project also includes data cleaning, feature engineering, exploratory data analysis, feature scaling, PCA, clustering evaluation, stability testing, and a Streamlit dashboard for visualising the results.

---

## Project Objectives

The main objectives of this project are:

- Clean and prepare the customer dataset
- Create useful features for customer segmentation
- Explore customer spending and purchasing behaviour
- Apply different clustering algorithms
- Compare K-Means, DBSCAN, and GMM
- Evaluate the quality of the clusters
- Identify useful customer segments
- Present the results through an interactive Streamlit dashboard

---

## Dataset

The project uses the **Customer Personality Analysis** dataset.

The dataset contains customer information such as:

- Year of birth
- Education
- Marital status
- Income
- Number of children
- Customer enrolment date
- Recency
- Spending behaviour
- Purchase behaviour
- Campaign responses
- Web activity
